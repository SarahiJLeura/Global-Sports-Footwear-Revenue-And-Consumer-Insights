\section{Introduction}
This project focuses on predicting the number of units sold for sports footwear products using historical transactional data from 2018 to 2026. The task is formulated as a supervised learning regression problem, where the target variable is discrete. By applying the Knowledge Discovery in Databases (KDD) methodology, the project aims to systematically select, preprocess, transform, and analyze the data to build predictive models capable of capturing the relationships between pricing, discounts, brand, customer characteristics, sales channels, and demand.

The ultimate objective is to develop a demand regression model that can support decision-making processes in inventory planning, pricing optimization, and marketing strategy within the sports footwear industry.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% 1.1. Domain explanation
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\subsection{Domain explanation}

People are also increasingly realizing the importance of using the appropriate type of shoes for sports activities. As a result, the demand for athletic shoes is expected to register a sharp rise over the coming years. The demand for athletic footwear products is increasing rapidly owing to their usage in various conditions. Athletic footwear products are used by various consumers such as athletes and climbers. In addition, there are fitness-conscious customers, gym-goers, and people who use them for mild fitness routines. Various types of athletic footwear available in the market are prepared from high-quality raw types, such as leather, foam, and plastic, which involve the use of advanced chemical additives \cite{grandview_athletic_footwear_2024}.

The global sports footwear market is dominated by major brands such as: Nike, Adidas, Pumas, Reebok, ASICS, New Balance. The demand in industry is influenced by multiple factors:
\begin{itemize}
  \item Pricing strategies
  \item Promotional discounts
  \item Consumer income level
  \item Sales channel (online vs retail)
  \item Brand
  \item Product category
  \item Gender
  \item Country
\end{itemize}

Understanding these relationships allows companies to improve revenue and reduce overstock or understock situations.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% 1.2. Problem description
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\subsection{Problem description}

The objective of this project is to predict the number of units sold of sports footwear products using historical transactional data. The dataset includes information about pricing, discounts, brand, sales channel, customer income level, and product ratings. The dataset cover information from 2018 to 2026.

Accurate demand prediction is crucial in the retail industry because it allows companies to optimize inventory management, pricing strategies, and promotional campaigns. This project focuses on a supervised learning regression task, where the target variable is discrete (number of units sold).

\subsection{KDD methodology}
Knowledge Discovery in Databases (KDD) is the overall process of discovering useful patterns and knowledge from large volumes of data \cite{kdd_process}. The main idea is make better decisions (See Figure~\ref{fig:kdd_process}).
\begin{enumerate}
  \item \textbf{Data selection.} Involves choosing relevant data from one or more sources according to the problem.
  \item \textbf{Data Preprocessing.} The selected data is cleaned and prepared by handling missing values, noise, and inconsistencies to improve its quality. 
  \item \textbf{Data transformation.} The cleaned data is converted or consolidated into suitable formats or structures that will be analyzed.
  \item \textbf{Data mining.} This is the core task where algorithms are applied to extract patterns, relationships, or models from transformed data.
  \item \textbf{Interpretation and Evaluation.} The results obtained from data mining are examined and interpreted to determine their usefulness and relevance. Also, retrieve insights.
\end{enumerate}

\subsection{Data selection}

The dataset used in this project was obtained from Kaggle and contains more than 30,000 records of global sports footwear sales covering the period from 2018 to 2026 \cite{footwear2026}. It includes transactional and product-level information such as price, discount percentage, brand, product category, sales channel (online or retail), customer income level, country, gender, product ratings, and the number of units sold.

This dataset was selected because it closely reflects real-world retail data structures and contains a diverse set of explanatory variables that influence demand. Additionally, the combination of numerical and categorical features makes it well-suited for supervised learning regression tasks, enabling the development and evaluation of predictive models for demand forecasting.

The dataset provides sufficient variability and scale to support robust model training, validation, and testing, making it appropriate for applying the Knowledge Discovery in Databases (KDD) methodology described earlier.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% 2.2. Data description
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\subsection{Dataset description}

The dataset consists of transactional-level sales records from the global sports footwear market covering the period 2018--2026. Each row represents a single purchase transaction and contains product, pricing, customer, sales channel, and financial information associated with that transaction. The dataset integrates both categorical and numerical attributes, allowing the modeling of complex relationships that influence product demand.

From a structural perspective, the dataset can be grouped into five main categories of variables:

\begin{itemize}
    \item \textbf{Product Information:} Includes attributes that describe the physical and commercial characteristics of the footwear product. These variables are \textit{brand}, \textit{model\_name}, \textit{category}, \textit{gender}, \textit{size}, and \textit{color}.
    
    \item \textbf{Pricing Information:} Contains monetary attributes related to pricing strategy, namely \textit{base\_price\_usd}, \textit{discount\_percent}, and \textit{final\_price\_usd}.
    
    \item \textbf{Customer Information:} Includes socio-economic and behavioral indicators such as \textit{customer\_income\_level}, \textit{customer\_rating}, and \textit{country}.
    
    \item \textbf{Sales Channel Information:} Comprises \textit{sales\_channel} and \textit{payment\_method}, which describe how and where the transaction occurred.
    
    \item \textbf{Financial Metrics:} The attribute \textit{revenue\_usd} represents the total revenue generated per transaction. This variable is directly related to \textit{units\_sold} and \textit{final\_price\_usd}.
\end{itemize}

The target variable of the study is:

\begin{itemize}
    \item \textbf{Units Sold:} A discrete numerical variable representing the number of footwear units purchased in a single transaction. Although integer-valued (ranging from 1 to 4), it is modeled as a continuous regression target because it represents quantity demand.
\end{itemize}

Overall, the dataset presents a multivariate structure with mixed data types, moderate dimensionality (18 attributes), and balanced categorical distributions. The combination of product-level, pricing, customer, and channel-related variables makes it suitable for supervised learning regression models.
